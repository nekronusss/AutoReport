# Runbook

Сначала `dqflow status --period YYYY-MM-DD --json`. Состояния данных, отчёта и
уведомления независимы. Подробности: meta.runs, attempts, check_results,
rejected_records, outbox, audit_events. Логи stdout JSON-summary, stderr JSON stages.

| Симптом | Действие |
|---|---|
| FAILED_SOURCE | Проверить готовность снимка, HTTP-код и доступ. После восстановления — retry |
| FAILED_DQ | Посмотреть rule_id и до 20 технических ID. Получить исправленный snapshot_id, выполнить run |
| FAILED_TECH | Проверить диск, БД, dbt console.log в artifacts/dbt/run_id; затем retry |
| PUBLISHED_REPORT_PENDING | Исправить права/место в artifacts; `report --period D`. Повторная загрузка не нужна |
| Notification DEAD | Проверить endpoint/auth; после исправления вручную вернуть событие в PENDING, available_at=now() |
| Код 75 | Другой runner удерживает session advisory lock. Дождаться завершения; не считать дату свежей |
| Зависший run | Проверить heartbeat и процесс. Завершить неисправный процесс штатными средствами; retry после освобождения lock |
| Ошибочный релиз | Приостановить timers, вернуть предыдущий совместимый digest; rollback периода — отдельная операция |
| Потеря сервера | Изолированный restore, doctor, сверка артефактов/сумм, replay, затем catchup |

Rollback требует совпадения dataset/period и статуса проверенной версии. Причина обязательна.
Текущий отчёт определяется текущим run_id: если артефакта нет, UI показывает ожидание,
а не отчёт другой версии. Старый as_of автоматически новую публикацию не заменяет.

Cleanup намеренно консервативен: удаляет raw/кандидатов неуспешных непривязанных
запусков после TTL и подтверждённой внешней копии; проверенные исторические версии,
их отчёты и аудит сохраняются для rollback. Полное автоматическое удаление по всем
TTL требует согласованного списка сохраняемых версий и пока не включено.

Перед production заполнить: технический владелец, владелец источника, получатель отчёта,
канал критических уведомлений, часы реакции и контакт на восстановление.
Эти персональные/организационные сведения в ТЗ не заданы.
